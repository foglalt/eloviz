# Phase 03 Plan 25: Sort study references in Bible order

## Objective

Display the public study page's Scripture references in canonical Bible order,
then by chapter and verse within each book, without changing stored evidence.

## Context

- @.planning/PROJECT.md
- @.planning/ROADMAP.md
- @.planning/STATE.md
- @.planning/phases/03-evergreen-content-library/03-CONTEXT.md

## Tasks

1. Expose a stable canonical-order sorter from the existing 66-book reference catalogue.
2. Apply the sorter at the public study-page rendering boundary.
3. Cover book/chapter/verse ordering, invalid fallback, and non-mutation with tests.

## Verification

- `npm run test:references`
- `npm run lint`
- `npx tsc --noEmit`
- `npm run build`
- GTD phase verification and repository health.

## Success Criteria

- Study references render from Genesis through Revelation, with earlier chapters
  and verses first inside the same book.
- Stored detection order and reference data remain unchanged.
