# Phase 03 Plan 14: Refine public preview metadata and sizing

## Objective

Make public previews more consistent by hiding YouTube channel names until the video detail page and constraining every preview description to a fixed three-line block with an ellipsis.

## Context

- @.planning/PROJECT.md
- @.planning/ROADMAP.md
- @.planning/STATE.md
- @.planning/phases/03-evergreen-content-library/03-CONTEXT.md

## Tasks

1. Remove channel names from shared public video rows and public video search-result metadata.
2. Keep speaker metadata in previews, channel-based search matching, admin metadata, and channel display on `/videok/[slug]`.
3. Wrap study/video row descriptions consistently and clamp all resource and search-result preview descriptions to three reserved lines.
4. Add regression coverage for finding a video by channel without exposing that channel in result metadata.

## Verification

- `npm run test:search`
- `npm run lint`
- `npx tsc --noEmit`
- `npm run build`
- Render video listings, search results, and a selected video page at desktop and mobile widths.

## Success Criteria

- Public video previews and search results do not display the YouTube channel.
- Video previews may still display the speaker, and searching by channel name still finds the video.
- The selected video page still displays the channel, and admin channel metadata is unchanged.
- Preview descriptions reserve exactly three lines and truncate longer copy with an ellipsis.
- Resource and search rows remain aligned without horizontal overflow at supported widths.
