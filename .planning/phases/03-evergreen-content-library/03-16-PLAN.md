# Phase 03 Plan 16: Add admin save keyboard shortcut

## Objective

Let editors save the active topic, study, or video form with Ctrl+S on Windows
and Linux or Command+S on macOS, using the same validated Server Action and
pending-state flow as the visible save button.

## Context

- @.planning/PROJECT.md
- @.planning/ROADMAP.md
- @.planning/STATE.md
- @.planning/phases/03-evergreen-content-library/03-CONTEXT.md

- @src/app/admin/temak/page.tsx
- @src/app/admin/tanulmanyok/page.tsx
- @src/app/admin/videok/page.tsx

## Tasks

1. Add an opt-in keyboard shortcut to the shared admin submit control.
2. Enable the shortcut only for the three content-edit forms, excluding PDF
   upload, deletion, search, login, and logout forms.
3. Preserve native constraint validation, block the browser Save Page command,
   and ignore duplicate shortcut submissions while a save is pending.
4. Add focused shortcut recognition tests and verify the real form behavior.

## Success Criteria

- Ctrl+S and Command+S submit the active topic, study, or video edit form.
- The shortcut goes through browser validation and the existing pending modal.
- Holding the shortcut or pressing it while pending does not submit again.
- Other admin forms are not submitted by the shortcut.
