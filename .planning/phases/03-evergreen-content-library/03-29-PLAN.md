# Phase 03 Plan 29: Publish PDF-derived HTML studies

## Objective

Turn each text-readable study PDF into a versioned semantic HTML reading
experience while retaining the original PDF as the downloadable source.

## Context

- @.planning/PROJECT.md
- @.planning/ROADMAP.md
- @.planning/STATE.md
- @.planning/phases/03-evergreen-content-library/03-CONTEXT.md

## Tasks

1. Extend PDF extraction with layout-aware headings, paragraphs, Scripture
   excerpts, lists, page-continuation handling, and safe versioned storage.
2. Add the additive database migration, automatic upload-time generation,
   seed support, and a one-time backfill for existing documents.
3. Render the semantic article on public study pages while keeping the PDF
   action and moving connected canonical references below it in the sidebar.
4. Verify converter regressions, publication behavior, responsive reading
   layout, production migration/backfill, and the deployed page.

## Verification

- `npm run test:article`
- `npm run test:pdf`
- Existing reference, publication, search, storage, and topic tests.
- `npm run lint`, `npx tsc --noEmit`, and `npm run build`.
- PostgreSQL migration/backfill checks and desktop/mobile rendered-page checks.

## Success Criteria

- The study page contains the complete converted article as semantic HTML.
- The original PDF remains available under `Dokumentum`.
- Canonical connected passages appear in Bible order below the PDF action.
- New uploads generate article content atomically with the document and ranges.
