# Phase 03 Plan 26: Filter study search by Scripture ranges

## Objective

Add an optional Scripture-range filter to public catalogue search so studies can
be found by any stored reference interval that overlaps the requested passage.

## Context

- @.planning/PROJECT.md
- @.planning/ROADMAP.md
- @.planning/STATE.md
- @.planning/phases/03-evergreen-content-library/03-CONTEXT.md

## Tasks

1. Parse one Hungarian Scripture reference or range into a canonical OSIS interval.
2. Apply inclusive interval-overlap matching to bundled and PostgreSQL study search.
3. Add an accessible URL-persistent search-page filter, validation, guidance, and responsive styling.
4. Cover parsing, containment, overlap, adjacency, verse-only search, and combined filters.

## Verification

- `npm run test:references`
- `npm run test:search`
- `npm run lint`
- `npx tsc --noEmit`
- `npm run build`
- Local and deployed HTTP checks for overlapping and non-overlapping passages.
- GTD phase verification and repository health.

## Success Criteria

- `Jn 3:4-8` finds a study referencing `Jn 3:1-5`, while an adjacent but
  non-overlapping interval does not.
- Verse-only and combined text-plus-verse searches retain their URL state and
  provide clear Hungarian feedback for invalid reference syntax.
