# Phase 03 Plan 18: Published default for new topics

## Objective

Make newly created topics default to the published state without changing the
saved status of existing topics or the draft-first behavior of other content
types.

## Context

- @.planning/PROJECT.md
- @.planning/ROADMAP.md
- @.planning/STATE.md
- @.planning/phases/03-evergreen-content-library/03-CONTEXT.md

## Tasks

1. Add a configurable new-record status to the shared admin content fields.
2. Select `published` only for the new-topic editor.
3. Verify creation and editing defaults, then run the standard quality checks.

## Verification

- Confirm the new-topic form selects `published`.
- Confirm an existing draft topic still selects `draft`.
- Confirm new study and video forms still select `draft`.
- Run ESLint, strict TypeScript, the production build, and GTD verification.

## Success Criteria

- New topics default to public/published.
- Editing preserves the topic's stored state.
- Other content types retain their current defaults.
