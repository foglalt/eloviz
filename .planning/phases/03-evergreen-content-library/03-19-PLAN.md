# Phase 03 Plan 19: Binary publication state switch

## Objective

Replace the publication-state dropdown with one clear binary switch throughout
the shared admin editor while preserving each content type's initial state.

## Context

- @.planning/PROJECT.md
- @.planning/ROADMAP.md
- @.planning/STATE.md
- @.planning/phases/03-evergreen-content-library/03-CONTEXT.md

## Tasks

1. Render the state field as an accessible native checkbox switch.
2. Preserve exact `draft` and `published` form values without client JavaScript.
3. Style and verify both switch positions across topic, study, and video forms.

## Verification

- Confirm new topics show an on/published switch.
- Confirm new studies and videos show an off/draft switch.
- Confirm switching serializes the expected status value in both positions.
- Run ESLint, strict TypeScript, production build, GTD verification, and health.

## Success Criteria

- The state control is a simple two-position switch rather than a dropdown.
- All existing default and edit-state behavior remains intact.
- The switch is keyboard-operable, labelled, and visually clear.
