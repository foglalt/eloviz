# Phase 03 Plan 12: Remove redundant resource type labels

## Objective

Remove repeated resource-type labels from list items when the surrounding section already identifies the item type, reducing visual noise without changing detail-page context or useful metadata.

## Context

- @.planning/PROJECT.md
- @.planning/ROADMAP.md
- @.planning/STATE.md
- @.planning/phases/03-evergreen-content-library/03-CONTEXT.md

## Tasks

1. Remove the `PDF tanulmány` and `Videóajánló` eyebrow labels from shared public resource rows.
2. Remove the `Téma`, `PDF-tanulmány`, and `Videóajánló` labels from items inside grouped search results.
3. Preserve section headings, titles, topic tags, references, speakers, channels, and detail-page eyebrow labels.

## Verification

- `npm run lint`
- `npx tsc --noEmit`
- `npm run build`
- Confirm source no longer renders type eyebrows inside `StudyRows`, `VideoRows`, or `CatalogSearchResults`.

## Success Criteria

- Public resource lists show each title immediately, without repeating the surrounding section’s content type.
- Grouped search results retain their `Témák`, `Tanulmányok`, and `Videók` headings but do not repeat the type above every result.
- Detail pages retain their contextual eyebrow labels.
