# Phase 03 Plan 13: Add route-aware multi-type search filters

## Objective

Add a multi-select public-search filter for topics, studies, and videos, and automatically scope compact header searches to the current catalogue route.

## Context

- @.planning/PROJECT.md
- @.planning/ROADMAP.md
- @.planning/STATE.md
- @.planning/phases/03-evergreen-content-library/03-CONTEXT.md

## Tasks

1. Define and test canonical parsing for selected content types plus route-to-filter defaults.
2. Make public catalogue search return and query only the selected content types.
3. Add accessible multi-select controls to the search page while submitting hidden route-derived defaults from compact header searches.
4. Verify desktop/mobile layout, URL persistence, route defaults, and single/multiple/all-type results.

## Verification

- `npm run test:search`
- `npm run lint`
- `npx tsc --noEmit`
- `npm run build`
- Render and inspect route-derived and multi-select search URLs in the production server.

## Success Criteria

- Searches submitted from `/temak`, `/tanulmanyok`, and `/videok` default respectively to topics, studies, and videos.
- The search page exposes three checked/unchecked controls and supports any non-empty combination.
- Selected filters remain visible in the URL and after results render.
- Unselected result groups are not queried or displayed.
