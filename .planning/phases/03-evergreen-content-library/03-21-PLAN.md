# Phase 03 Plan 21: Temporarily hidden SEO editor fields

## Objective

Temporarily remove the optional SEO override controls from topic, study, and
video admin editors without deleting the data model or clearing stored values.

## Context

- @.planning/PROJECT.md
- @.planning/ROADMAP.md
- @.planning/STATE.md
- @.planning/phases/03-evergreen-content-library/03-CONTEXT.md

## Tasks

1. Replace the shared visible SEO controls with hidden fields that retain the
   current record values during every save.
2. Confirm new and existing topic, study, and video forms no longer expose SEO
   editing while preserving the existing server-action contract.
3. Run static, production-build, rendered-form, memory, and deployment checks.

## Verification

- The shared admin form contains no visible SEO label, input, or textarea.
- Existing SEO values remain present in submitted `FormData`; new records send
  empty values and retain the current metadata fallback behavior.
- ESLint, strict TypeScript, production build, browser QA, GTD verification,
  repository health, and live deployment checks pass.

## Success Criteria

- No topic, study, or video admin editor displays SEO controls.
- Saving unrelated changes cannot silently erase an existing SEO override.
- SEO schema fields, validation, server actions, and public metadata behavior
  remain available for a future editor reintroduction.
