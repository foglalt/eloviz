# Phase 04 Plan 11: Convert red PDF text to bold emphasis

## Objective

Convert red text in newly uploaded PDFs to semantic bold in the generated HTML
study while retaining normal site fonts/colors and exact text/reference behavior.

## Context

- @.planning/PROJECT.md
- @.planning/ROADMAP.md
- @.planning/STATE.md
- @.planning/phases/04-simple-bible-reader/04-CONTEXT.md

## Tasks

1. Read PDF painting colors and match them conservatively to extracted glyph text.
2. Carry bounded emphasis ranges through layout cleanup, lists, JSON validation
   and rendering; preserve clickable Bible reference detection over styled words.
3. Test real PDF RGB/CMYK/graphics state, structural/text regressions, backward
   compatibility and invalid offsets; visually compare PDF and website fixture.
4. Run reliability checks, release, verify existing production pages and record
   evidence. Existing publications are not automatically regenerated.

## Verification

- Focused PDF/article tests and full regression suite; GTD lint/build/TypeScript.
- Real PDF fixture render and actual desktop/mobile website reader checks;
  original study text/list/reference output compared with previous extraction.

## Success Criteria

- Red PDF words become strong text, surrounding text stays normal; original PDF
  remains intact, old articles load and Bible links retain their full references.
