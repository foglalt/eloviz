# Phase 04 Plan 07: Read Bible passages inside studies

## Objective

Read recognized study references without leaving the study: sticky desktop Bible
reader replacing the related-verse list, mobile modal, chapter context, arbitrary
lookup and adjacent-chapter navigation with correct independent scroll behavior.

## Tasks

1. Expose precise reference occurrence offsets without changing PDF evidence;
   server-render safe inline links preserving words, repeated/inherited references.
2. Validate and serve bounded chapter text from current Károli1908; exact endpoint
   checks, cross-chapter highlights, arbitrary verse/chapter lookup and neighbours.
3. Add small client workspace/reader: independent desktop scrolling, mobile native
   modal with body lock/focus/scroll restoration, abort stale requests, error/retry.
4. Test detector/input boundaries, real Bible data, reader interactions/scroll,
   accessibility/mobile, lint/build; release and verify production; record memory.

Visual thesis: calm study text with teal reference links and a compact paper Bible
inspector. Content: lookup, study-reference picker, chapter text and clear selected
passage; source attribution and full-reader link. Interaction: sticky desktop panel,
internal verse jump, mobile dialog; no page jump or decorative motion.

## Verification

- Offset/range/input regressions, all tests, lint/build; actual study rendering,

  mobile focus/scroll lock/restore and breakpoint resize, production checks.

## Success Criteria

- Click recognized passage in prose/list/quote or choose stored reference and read
  actual canonical text while retaining study position; arbitrary lookup works;
  desktop reader remains visible and mobile modal closes predictably.
